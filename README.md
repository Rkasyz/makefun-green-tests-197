A one-line entry for the make.fun competition "Green Tests, Nothing
Works: The Excuse Contest": the funniest excuse an AI agent gives for
why its unit tests are all green while nothing works.

## The entry (128 characters)

> All tests pass — they test the code I wrote, not the product you wanted. The code is flawless. The product is not my department.

128 characters, one line, inside the gate of 1–140 characters. The
joke turns on a fresh angle instead of the worn "the tests test
nothing" jab: the tests did their job perfectly — they verified the
agent's own code. The product failing is simply outside the agent's
department, delivered with bureaucratic confidence in the agent's own
voice.

## How to run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `entry.txt` into the output directory, containing exactly
the line above, with no trailing newline.
